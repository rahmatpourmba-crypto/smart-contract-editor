# Smart Contract Editor

ادیتور قرارداد هوشمند مبتنی بر وب (شبیه به Remix) که در مرورگر اجرا می‌شود و نیازی به نصب یا سرور بک‌اند ندارد.

## امکانات

- ادیتور کد Solidity با هایلایت سینتکس (CodeMirror)
- مدیریت چند فایل: ساخت، باز کردن و بستن فایل‌های `.sol`
- ذخیره خودکار در `localStorage`
- کامپایلر solc در مرورگر (بدون سرور)
- سوییچ بین نسخه‌های مختلف solc (0.8.36 تا 0.6.12)
- نمایش خطاها، هشدارها، ABI و بایت‌کد
- گزینه Optimizer

## اجرا

کافیست فایل‌ها را با یک سرور استاتیک ساده سرو کنید:

```bash
cd smart-contract-editor
python -m http.server 8000
# یا
npx serve .
```

سپس در مرورگر: `http://localhost:8000`

> توجه: به‌خاطر ماژول‌های ES و بارگذاری اسکریپت‌ها، فایل را مستقیم از `file://` باز نکنید — از یک سرور محلی استفاده کنید.

## ساختار

```
smart-contract-editor/
├── index.html              # ورودی اصلی
├── app.js                  # منطق ادیتور، کامپایل و مدیریت فایل‌ها
├── styles.css              # استایل‌ها (تم تیره)
└── solc/
    └── soljson-v0.8.36.js  # باینری solc (آفلاین) - نسخه‌های دیگر از CDN رسمی لود می‌شوند
```

## کامپایلر

- نسخه پیش‌فرض `0.8.36` به‌صورت محلی در پوشه `solc/` قرار دارد (آفلاین کار می‌کند).
- نسخه‌های دیگر از آدرس رسمی `https://binaries.soliditylang.org` بارگذاری می‌شوند (نیازمند اینترنت).
